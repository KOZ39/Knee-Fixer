# Knee Fixer

[English](README.md) | 한국어 | [日本語](README_JA.md)

> VRChat 아바타의 무릎을 비파괴 방식으로 보정하는 도구입니다.

## 요구 사항

- Unity 2022.3.22f1
- [Modular Avatar](https://modular-avatar.nadena.dev/)

## 설치

[VPM 저장소](https://koz39.github.io/vpm-listing/)에서 "Add to VCC"로 저장소를 추가한 뒤, VCC 또는 ALCOM의 프로젝트 관리에서 Knee Fixer 패키지를 추가합니다.

## 사용법

1. 하이어라키에서 아바타를 우클릭하고 Knee Fixer > Setup을 선택합니다.
2. 인스펙터에서 아바타에 맞는 프리셋을 선택합니다.
3. 프리셋이 없으면 무릎 깊이 값을 직접 조절합니다. 프로젝트 창의 Create > Knee Fixer > Preset으로 커스텀 프리셋을 생성할 수도 있습니다.
4. 아바타를 빌드할 때 자동으로 적용됩니다.
